# 動画の台本（スコア版）— 空残り（そらのこり）

> 元の版の台本は [presentation.md](presentation.md)、耐用年数版の台本は [presentation2.md](presentation2.md) に残しています。
> スライドは PowerPoint `空残り_スコア版.pptx`（`docs/slides/build_pptx.js` の score 指定で作成）を使います。
> 数値は 2026-11-19 にこのページで実際に数えた結果です（東本願寺の近く・7階・北向き・画角60°、20年、格子 20×12）。撮影時の画面の数字が違ったら、画面の数字を読んでください。

## 伝えたいこと（一言）

窓から見える景色を建物1棟ずつに分け、**建物ごとの「寿命の目安」（建築年＋耐用年数）から、景色がどれだけ安定しているかを点数で示す**。

## 撮影のメモ

- 録画の前に例の窓のリンクを開き、建物の読み込みが終わるまで待つ（数えるボタンは、読み込みが終わるまで自動で待つ）。
- 「景色を数える」「20年後の景色を数える」は時間がかかる場合がある。待ち時間は動画編集で早送りする。遅い場合は格子を「速い（20×12）」にする。
- ベスト5の行をもう一度クリックすると、光るのが消える。
- 最後に「元に戻す」を押すと、消えた建物が戻る。
- 言い方の注意: 耐用年数は税金の計算のための年数で、実際の寿命や建て替え計画ではない。スコアの3段階（80点以上・50点以上）は目安。ナレーションでは「目安」と言う。
