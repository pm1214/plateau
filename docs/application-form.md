## 作品の概要・アピールポイント（400）　（344文字 / 上限400）

```
マンションの窓からの眺めは、周りの建て替えで将来変わるかもしれません。本作は、窓から見える景色をPLATEAUの建物1棟ずつの属性で「中身」まで分解し、変わりやすさを数えるWebアプリです。地図で窓の位置・階数・向きを決めると、画面を格子に区切って空・地面・建物の割合や、見える建物の用途・棟数を集計します。建物ごとに「建築年＋耐用年数（構造・用途ごと）」で建て替え時期の目安を出し、「20年後までに景色の37%が耐用年数を迎える」と示します。その建物がなくなった場合や、仮の建物を置いた場合の景色とも比べられ、夕日が見える時刻も判定します。既存の作品やサービスが景色を「見せる」のに対し、本作は建物属性で景色を「数える」点が特長です。ブラウザだけで動き、リンクで同じ景色を共有できます。
```

```
「おすすめの窓」ボタンで、京都タワーを望む窓や東京駅の窓にも切り替えられます。

■ 特にアピールしたい点
・景色を「見せる」のではなく「数える」。建物ごとに用途・構造・建築年を持つPLATEAUだからこそできる分析です。
・建物の寿命の目安を、国の耐用年数（構造・用途ごと）で一棟ずつ計算。建て替え時期で色分けした街の姿も見られます。
・意外な発見：東本願寺付近の窓では、20年後までに耐用年数を迎える建物がすべてなくなっても、空は45%→46%とほとんど増えませんでした。手前の古い家の奥にある、寿命の長い建物が見えるようになるだけです。眺望は「古い建物が多いから開ける」とは限らないことが数値でわかります。
・夕日が窓から見える時刻を、太陽の方向に視線を飛ばして判定します。

■ データについて
東京23区の2025年度データには建築年がなかったため、建築年が整備された京都市を対象にしました。東京駅周辺では、代わりに低い建物の割合を表示します。

■ 限界
目線の高さは「階数×3m」と仮定しています。耐用年数は税務上の年数で、実際の寿命や建て替え計画ではありません。構造が不明な建物（京都駅周辺の約26%）は判定できません。
```
