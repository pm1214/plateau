## 作品の概要・アピールポイント（400）　（383文字 / 上限400）

```
マンションの窓からの眺めは、周りの建て替えで将来変わるかもしれません。本作「空残り（そらのこり）」は、窓から見える景色をPLATEAUの建物1棟ずつの属性で「中身」まで分解し、その景色がどれだけ安定しているかを数えるWebアプリです。地図で窓の位置・階数・向きを決めると、画面を格子に区切って空・地面・建物の割合を集計します。建物ごとに「建築年＋耐用年数（構造・用途ごと）」で建て替え時期の目安を出し、「20年後までに景色の37%が耐用年数を迎える」「安定性スコア63点」と示します。景色を大きく占める建物ベスト5も、構造・建築年つきで示します。その建物がなくなった場合の景色との比較や、夕日が見える時刻の判定もできます。既存の作品が景色を「見せる」のに対し、本作は建物属性で景色を「数える」点が特長です。住まい選びや、開発時の窓の向きの検討、景観の検討に使えます。
```

```
■ 審査員の方へ：すぐ試せます
入り口：https://pm1214.github.io/plateau/
スライドの例の窓（東本願寺の近く・7階・北向き、スコア版）をそのまま開くリンク：https://pm1214.github.io/plateau/window3.html?lat=34.98950&lon=135.75600&floor=7&heading=0&fov=60&years=20
「おすすめの窓」で京都タワーや東京駅の窓にも切り替えられます。

■ 特にアピールしたい点
・景色を「見せる」のではなく「数える」。建物ごとに用途・構造・建築年を持つPLATEAUだからこそできる分析です。
・建物の寿命の目安を、国の耐用年数（構造・用途ごと）で一棟ずつ計算。建て替え時期で色分けした街の姿も見られます。
・景色の安定性スコア（0〜100点）と、景色を大きく占める建物ベスト5（クリックで3Dの建物が光る）で、どの建物が眺望を左右しているかがわかります。
・意外な発見：東本願寺付近の窓では、20年後までに耐用年数を迎える建物がすべてなくなっても、空は45%→46%とほとんど増えませんでした。奥の寿命の長い建物が見えるだけです。眺望は「古い建物が多いから開ける」とは限らないことが数値でわかります。

■ どう役立つか
住まい選び（部屋の比較・内見前の確認）、販売・仲介（眺望の目安）、開発・設計（窓の向きの検討）、まちづくり・景観（大事な眺めをつくる建物の洗い出し）。ブラウザだけで動き、建築年と構造がある都市なら読み込み先を変えるだけで広げられます。

■ 技術とデザインの工夫
1,000点を1点ずつ判定し建物IDで重複なく集計、太陽方向への視線で夕日を判定、読み込み完了を待ってから集計。おすすめの窓・共有リンク・色覚の多様性に配慮した配色で、誰でもすぐ試せます。

■ データについて
東京23区の2025年度データには建築年がないため、京都市を対象にしました（東京駅周辺は低い建物の割合を表示）。

■ 限界
目線の高さは「階数×3m」と仮定しています。耐用年数は税務上の年数で、実際の寿命や建て替え計画ではありません。構造が不明な建物（京都駅周辺の約26%）は判定できません。
```
