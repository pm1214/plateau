# 動画の台本（耐用年数版）

> 耐用年数版 `viewer/window2.html`（公開: https://pm1214.github.io/plateau/window2.html ）で撮る、3分以内の動画の台本です。
> 元の版の台本は [presentation.md](presentation.md) に残しています。スライドは `docs/slides/index2.html`（耐用年数版）を使います。
> 数値は 2026-11-19 にこのページで実際に数えた結果です（東本願寺の近く・7階・北向き・画角60°、格子 20×12）。撮影時の画面の数字が違ったら、画面の数字を読んでください。

## 伝えたいこと（一言）

窓から見える景色を建物1棟ずつに分け、**建物ごとの「寿命」（建築年＋耐用年数）から、何年後にどれだけ変わりうるかを数える**。

## 台本

画面はすべて `window2.html`。各場面は「おすすめの窓」ボタンで呼び出せる。H キーでパネルを隠す・出す。

## 撮影のメモ

- 録画の前に一度「窓から見る」にして、建物の読み込みが終わるまで待つ（数えるボタンは、読み込みが終わるまで自動で待つ）。
- 「20年後の景色を数える」は、今と20年後の2回数えるので時間がかかる。待ち時間は動画編集で早送りする。
- スライダーで色が変わる場面（0:22〜）は、上から見た状態のほうが変化がわかりやすい。
- 最後に「元に戻す」を押すと、消えた建物が戻る。
- 言い方の注意: 耐用年数は税金の計算のための年数で、実際の寿命や建て替え計画ではない。ナレーションでは「目安」と言う。

## 確認済みの数値（2026-11-19）

| 項目 | 値 |
| --- | --- |
| 20年後までに耐用年数を迎える建物 | 視界の 37%（うち今すでに超えている 24%） |
| 判定できない建物（建築年か構造が不明） | 視界の 15% |
| 20年後の景色（取り壊された場合） | 空 45% → 46%、地面 2% → 10%、今ある建物 53% → 44%、見える棟数 56 → 43 |
| 夕日（京都タワーを望む・10階・南西、11/18） | 15:55〜16:45 ごろ見える。日の入り 16:50 ごろ |
| 耐用年数の例（国税庁） | 木造住宅 22年、鉄骨造住宅 34年、鉄筋コンクリート造の事務所 50年 |
