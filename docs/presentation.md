## スライド構成（11枚）

### 1. 表紙
- タイトル: **窓の眺望診断** — その景色、あと何年もちますか？
- サブ: PLATEAU の建物属性で、窓から見える景色の「中身」を数える
- 画面写真: 窓の視点に点を重ねた画面（数えた点が色分けされているもの）
- 応募部門・氏名【要確認】

### 2. 課題
- マンションの眺望は、周りの建て替えで将来変わることがある
- 眺望は法律でほとんど守られず、買う前に自分で確かめるしかない【要確認：京都市には眺望景観を守る条例がある。個人の住まいの眺望を守るものかどうかを確かめて、表現を調整する】
- 今あるサービスは景色を「見せる」だけで、景色の中身や変わりやすさを「数えない」

### 3. ひとことで言うと
- 窓から見える景色を、建物1棟ずつの属性（用途・高さ・建築年）で分解し、**建て替えで変わりやすい景色かどうかを数値で示す**
- 例: 「この景色の18%は、築40年以上で建て替えで変わりやすい建物です」

### 4. 使い方（3ステップ）
1. 地図で窓の位置を選び、階数・向き・画角を決める
2. 「景色を数える」→ 空・建物・古い建物の割合が出る
3. 建物を消す・仮の建物を置く →「今」と「将来」を比べる

### 5. しくみ：景色を「数える」
- 画面を格子（40×25 = 1,000 点）に区切り、1点ずつ何が見えるかを調べる
  - 建物に当たった点 → その建物の ID・用途・建築年を記録
  - 当たらない点 → 視線が地面に届けば「地面」、届かなければ「空」
- 棟数は建物 ID で重複を除いて数える
- 目線の高さは「階数 × 3 m」と仮定（窓の位置はデータにないため）

### 6. 結果の例（京都駅の北・東本願寺付近、7階・北向き・画角60°）
| 項目 | 値 |
| --- | --- |
| 空 | 46% |
| 地面 | 3% |
| 建物 | 52%（54棟） |
| 用途 | 住宅 15棟、店舗等併用住宅 8棟、共同住宅 10棟 など |
| 築40年以上の建物 | 視界の 18% |
| 建築年が不明 | 視界の 13% |

（20×12 の格子で計測。画面写真を添える）

### 7. 将来の景色と比べる
- 手前の建物を1棟消し、高さ 60 m の仮の建物（幅40 m × 奥行き30 m）を置いた例
| | 今 | 将来 |
| --- | --- | --- |
| 空 | 46% | 37% |
| 今ある建物 | 52% | 49% |
| 新しい建物（仮） | 0% | 11% |
| 見える建物の棟数 | 54棟 | 48棟 |
- 「将来、空の見える割合は 46% → 37% に減ります」

### 8. なぜ京都か・なぜ PLATEAU か
- 景色の「古さ」を数えるには、建物ごとの建築年が必要
- 調べた範囲では、東京23区の 2025 年度データ（3地域）には建築年がなかった。京都駅周辺では 72% の建物に建築年があり、築40年以上が 975 棟（2,634棟中）
- PLATEAU は建物1棟ごとに ID・用途・高さ・階数・建築年を持ち、表示・非表示を切り替えられ、オープンデータなので集計が自由にできる

### 9. 既存作品・サービスとの違い（削らない）
| | 何をするか | 本作との違い |
| --- | --- | --- |
| PLATEAU Window（2022年 AWARD 入賞）【要確認：名称・受賞内容】 | 窓からの景色を見せる | 本作は景色を「数える」 |
| Google Earth／Google の3D地図 | 写実的な3D表示 | 建物の属性がない。規約上、3D画像から数値をプログラムで読み取れない【要確認：規約の該当箇所】 |
| Shadowmap | 日照と影 | 本作は景色の構成と建て替えのしやすさ |

### 10. これから（構想）
- 年度の違う PLATEAU データを比べて、景色が実際にどう変わってきたかを示す「眺望の寿命予測」
- 逆方向の眺望：自分の窓が周りのどの建物から見えるか
- 夕日が見えるかどうか（時刻を変える）
- ほかの都市へ広げる（建築年がある都市から）

### 11. 限界と工夫・出典
- 限界:
  - 目線の高さは「階数×3 m」という仮定
  - 高さは京都駅付近の実測値（63 m）で地面に合わせており、離れると誤差が出る
  - 建築年が不明な建物（データ上「1」）は「不明」として別に数える
  - 「築40年以上＝変わりやすい」は単純化した目安で、実際の建て替え計画ではない
- 出典: 国土交通省 Project PLATEAU（3D都市モデル）／国土地理院（背景地図）／CesiumJS
